# TipLink for BCH BLAZE 2026

TipLink is a Bitcoin Cash app for Send by Link and merchant payment requests. Built by Defi-Lord at Nazzitech.

- [Live app and presentation](https://www.tip-link.xyz/)
- [November 21 judging source](./TipLink-BLAZE-2026-2026-11-21.zip) from `b9df4304f3914c2506b0eb1d4a84257040c44de9`
- [November 12 pre-hackathon source](./TipLink-Pre-Hackathon-2026-11-12.zip) from `5bc094c40ccacbd3f6fb25165558004d2b832131`

Each ZIP includes the frontend, backend, and tests. Extract a snapshot and follow its README to run it locally. Internal operations notes and old export-review records were omitted. Source inspection does not grant an open-source license.

BLAZE updates include external-wallet payment tracking, synchronized merchant receipts for eligible requests, dashboard changes, and in-app help. A Selene payment was verified and synced to its merchant receipt on mainnet. The full funded send, claim, and onward withdrawal sequence still needs a live end-to-end check.
